# Login Page / Página de Login

🇧🇷 **Descrição (Português):**  
Este projeto foi criado para praticar os conceitos de CSS Grid Layout aprendidos. A página apresenta uma estrutura simples de login, com foco na organização visual e responsividade do conteúdo.

---

🇬🇧 **Description (English):**  
This project was created to practice the CSS Grid Layout concepts I learned. The page features a simple login structure, focusing on visual organization and content responsiveness.
